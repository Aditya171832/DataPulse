
# DataPulse

### Intelligent Cloud Data Engineering & Analytics Platform

DataPulse is a full-stack cloud-based data engineering and analytics
platform designed to help users upload, process, clean, analyze,
and visualize datasets.

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js, TypeScript
- Database: PostgreSQL
- Data Processing: Python, Pandas, NumPy, PySpark
- Machine Learning: Scikit-learn
- Cloud: Amazon Web Services (AWS)
- Infrastructure: Docker and GitHub Actions

## Main Features

- User authentication and workspace management
- Dataset upload and storage
- Automated data profiling
- Data cleaning and transformation
- ETL pipeline execution
- Machine learning insights
- Interactive analytics dashboards
- Cloud storage and monitoring

Currently under development.
